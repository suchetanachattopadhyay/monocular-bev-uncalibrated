# docs/

**`fileLog.docx`** — prose documentation of the *Sasken internship* vehicle-perception
system (ONNX MiDaS depth, YOLO detection, tracking, BEV rendering, 3D box overlay).

That is a **separate codebase** from the research pipeline in `scripts/`. It is included
here for context on prior related work, not as documentation of this repository. Nothing
in `scripts/` implements the tracking, trail, or cuboid-projection behaviour described in
this document.
